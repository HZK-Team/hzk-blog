Markdown 是一种轻量级标记语言，用简单的符号就能写出格式丰富的文本。本文将带你从零开始掌握 Markdown 的核心语法。

## 一、标题

使用 `#` 号表示标题，数量对应层级：

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 二、文本格式

| 语法 | 效果 | 说明 |
| --- | --- | --- |
| `**粗体**` | **粗体** | 两个星号包裹 |
| `*斜体*` | *斜体* | 一个星号包裹 |
| `~~删除线~~` | ~~删除线~~ | 两个波浪线 |
| `` `行内代码` `` | `代码` | 反引号包裹 |

## 三、列表

### 无序列表

```
- 苹果
- 香蕉
- 橙子
```

渲染效果：

- 苹果
- 香蕉
- 橙子

### 有序列表

```
1. 第一步
2. 第二步
3. 第三步
```

渲染效果：

1. 第一步
2. 第二步
3. 第三步

## 四、链接与图片

```
[链接文字](https://example.com)
![图片描述](image-url.png)
```

## 五、代码块

使用三个反引号包裹代码块，可以指定语言（展示语法本身时，外层用四个反引号包裹内层的三个）：

````markdown
```javascript
function hello() {
    console.log("Hello, Markdown!");
}
```
````

渲染效果：

```javascript
function hello() {
    console.log("Hello, Markdown!");
}
```

## 六、引用

```
> 这是一段引用文字
> 可以有多行
```

渲染效果：

> 这是一段引用文字，可以有多行。

## 七、表格

```
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
```

渲染效果：

| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |

## 八、分隔线

```
---
```

渲染效果：

---

> **提示：** 你可以使用 Typora、VS Code、MarkText 等编辑器编写 Markdown。

## 在这个博客上写作

现在，本博客已经内置了 Markdown 管线，不再需要手动转换 HTML：

1. 在 `posts/` 目录下新建 `.md` 文件
2. 文件开头的 front-matter 定义元数据
3. 写正文，然后运行构建脚本

```markdown
---
title: 文章标题
date: 2026-07-05
tags: [教程, Markdown]
excerpt: 一句话摘要
---

正文内容...
```

构建命令：

```bash
node scripts/generate-posts.js
```

部署到 Netlify 时构建会自动执行，只需要把 `posts/` 里的源文件提交到仓库即可。
